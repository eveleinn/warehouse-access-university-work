# Учёт складских материалов (MS Access)

## 📌 Контекст проекта
Это курсовая работа по базам данных. Цель — разработать реляционную базу данных для автоматизации учёта наличия, прихода и расхода материалов на складе. 

## 🎯 Функциональность
- Хранение информации о материалах, поставщиках, получателях, складах.
- Фиксация поступления и выдачи материалов.
- Автоматический подсчёт текущего остатка по каждому складу.
- Предоставление отчётов:
  - Наличие заданного материала по всем складам.
  - Наличие всех материалов на заданном складе.
  - Расход материалов с заданного склада за месяц.
  - Приход материалов на заданный склад за дату.
  - Расход заданного материала по всем складам за дату.
  - Выдача материалов заданному получателю за месяц.
  - Платёжная ведомость по поставщику на все склады.

## 📁 Состав репозитория
- `WarehouseDB.accdb` – файл базы данных.
- `screenshots/` – основные скриншоты 
- `queries/` – текстовые файлы с SQL-запросами.
